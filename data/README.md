# Data

Only data that may be redistributed is committed. Licensed inputs go in `data/external/`, which is git-ignored;
the pipeline skips the affected steps when they are missing.

```
data/
├── raw/                        # as downloaded (never edited by hand)
│   ├── binance/                # Binance.US 1-min klines, 1-21 Mar 2023: BTC/USD, BTC/USDC, BTC/USDT, USDC/USD, USDT/USD
│   ├── coinbase/               # Coinbase 1-min candles: BTC/USD, BTC/USDC*, BTC/USDT, BTC/EUR, USDC/EUR, USDT/EUR, USDT/USDC
│   ├── crypto_com/             # Crypto.com 1-min candles: BTC/USD, BTC/USDT, BTC/USDC**, USDT/USDC**
│   ├── kraken/                 # (optional) Kraken 1-min OHLCV used in the submitted paper - not distributed
│   ├── fx/                     # EUR/USD 1-min, March 2023 (HistData)
│   └── daily/                  # daily BTC/ETH/USDC/USDT OHLCV 2020-2026 (spillover analysis)
├── processed/                  # generated by `stablecoin-risk run clean` (git-ignored)
├── reserves/
│   ├── tetherassets.csv        # daily mark-to-market reconstruction of Tether's balance sheet
│   ├── circleassets.csv        # daily mark-to-market reconstruction of Circle's balance sheet
│   ├── circle_attestations.xlsx    # Circle monthly attestation line items (2021-2025)
│   └── reserves_analysis.xlsx      # quarterly totals, composition, MTM assumptions for both issuers
├── regression/
│   ├── usdc_regression_inputs.xlsx # sheets USDCDaily (exchange-day panel) + Circle (L, K, VIX)
│   └── usdt_regression_inputs.xlsx # sheets USDTDaily + Tether
└── external/                   # LICENSED - git-ignored, supply your own copies
    ├── traditional_market_data.xlsx   # Bloomberg: DXY, XAU, VIX, S&P 500, KBW daily OHLC
    ├── orderbook/<YYYY-MM-DD>/<PAIR>_ob_<YYYY-MM-DD>.csv   # CoinAPI level-1 snapshots
    └── genius_2025/            # 2025 1-min USDT/USD, USDC/USD (Binance.US), USDC/USDT (Binance)
```

\* Coinbase merged its USD and USDC books in 2022; BTC-USDC is the BTC-USD book quoted 1:1 and is treated as a
mirror (`config.MIRRORED_MARKETS`).
\*\* Dead feeds: zero volume and a frozen price for the whole window. Detected and excluded by
`loaders.is_active_market`.

## Schemas

Exchange files come in four schemas; `stablecoin_risk.data.loaders.standardize_ohlcv` maps all of them to
`timestamp (UTC) | open | high | low | close | volume | num_trades`.

| Source | Time column | Notes |
|---|---|---|
| Binance.US klines | `open_time_ms` (ms) | includes `num_trades` |
| Coinbase export A / Crypto.com | `open_time_ms` (ms) | no trade count |
| Coinbase export B | `start` (s) | `product_id`, `timestamp_utc` |
| Kraken via CoinAPI | `time_period_start` (ISO) | `price_open`, ..., `volume_traded`, `trades_count` |

## Licensed inputs

**`external/traditional_market_data.xlsx`** (Bloomberg). One sheet with columns
`Dates, Open _DXY, Last _DXY, High _DXY, Low _DXY, Open _XAU, ..., High _VIX, Low _VIX, ..., High _SP, Low _SP,
..., High _KBW, Low _KBW` (Bloomberg's default "Open _X" naming). Free substitutes: S&P 500 and VIX from FRED or
CBOE, DXY and gold from FRED/LBMA, KBW (BKX) from Nasdaq. Results will differ slightly.

**`external/orderbook/`** (CoinAPI, paid). Level-1 snapshots with columns `time_exchange, bid_price_1,
bid_size_1, ask_price_1, ask_size_1` (deeper levels are ignored).

## Re-collecting public data

```bash
stablecoin-risk collect-daily --start 2020-01-01 --end 2026-02-20     # daily panel via the source cascade
```

```python
from stablecoin_risk.data.collectors import fetch_binance_us_bulk, fetch_coinbase
fetch_binance_us_bulk("USDTUSD", "2025-01-01", "2025-12-31", interval="1m")   # 1-min klines
fetch_coinbase("BTC-USD", "2023-03-01", "2023-03-21", granularity=60)
```

Kraken's public API only serves the most recent 720 bars, so historical Kraken minutes must come from Kraken's
downloadable OHLCVT archive.

## Provenance of reserve data

Reserve compositions are compiled by hand from public attestation reports
([Tether](https://tether.to/en/transparency), [Circle](https://www.circle.com/transparency)), Q3 2022 – Q4 2025.
Daily values interpolate between attestations using duration-based mark-to-market: T-bills on the 3-month Treasury
yield, repo on SOFR, corporate bonds on AA curves, BTC and gold at market prices. See `docs/methodology.md`.
